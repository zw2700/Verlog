Qwen3-4B LM sampling experiments

Zero-shot reasoning mode × temperature

Does native thinking or higher sampling temperature improve multi-agent discussion and group decisions?

H1 · Reasoning mode: native thinking will elicit more substantive negotiation and improve group decisions.

H2 · Sampling: higher temperature will increase exploration and reduce premature consensus.

1
Design

2×2 LM sampling experiments

T = 1.0T = 1.3
Manual <THINK>100100
Native thinking100100
Each condition used the same 100 environment seeds; environment inputs matched exactly across conditions.
  • Preference strata: five exhaustive groups defined by which professors initially share the same top candidate (n = 10, 17, 19, 17, 37)
  • Per-call generation limit: 4,096 tokens
  • Shared communication budget: 500 tokens; only public GROUP messages count
  • Completion: 400/400 episodes; no invalid actions
2
Protocol

Only the reasoning interface changes

Manual <THINK>

  • Qwen-native thinking is disabled.
  • The prompt requires a literal <THINK>...</THINK> block.
  • That generated block remains in the agent’s private conversation history.

Native thinking

  • Qwen-native thinking is enabled through the chat template.
  • The prompt does not request a second literal <THINK> block.
  • Native reasoning is stripped before the environment receives the visible action.

Held fixed: visible action grammar, 4,096-token generation limit, environment, seeds, and 500-token public communication budget. Private reasoning is not charged to that shared budget.

This is an end-to-end protocol comparison—not a tokenizer-only isolation.

6
Mechanism · all 100 environments

Native ends early by following the first vote

89–93%vote on the first LM call
→
63–66%second voter copies the first despite preferring another candidate
→
57–64%consensus after exactly two LM calls

First-mover anchoring

With three professors and a 50% threshold, two matching votes end the episode. Professor 3 never acts in most native runs.

This is fast coordination—not evidence of deeper preference aggregation.

Length failures are not the cause

  • Native responses are ~12–13× longer per call than manual responses.
  • Only 1.8–2.0% of native calls hit the 4,096-token cap.
  • Truncation creates extra calls; it does not explain early termination.

Insight: native thinking is socially short but computationally long—and its consensus is first-mover-sensitive.
